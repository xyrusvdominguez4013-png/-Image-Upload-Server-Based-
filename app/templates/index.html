System Overview

This application demonstrates and benchmarks two common strategies for persisting user-uploaded images in a Flask + MySQL web application:

  • File System Storage — the image bytes are written to the server's disk (uploads/); only a file path and metadata row are stored in the database.
  • Database BLOB Storage — the image bytes are written directly into a MySQL LONGBLOB column, alongside its metadata.

Every upload is validated (extension, MIME type, size, and actual image content via Pillow) before it is persisted, and every upload/retrieval is timed so the two approaches can be compared with real numbers on the Comparison page.
