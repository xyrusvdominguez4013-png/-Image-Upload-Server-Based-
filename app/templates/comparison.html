File System — Advantages / Disadvantages
Advantages
  • Fast reads/writes, works well with a CDN
  • Keeps the database small and fast to back up
  • Scales horizontally with object storage (S3, NFS)
Disadvantages
  • Two systems (disk + DB) must be backed up and kept in sync
  • Requires careful path handling to avoid traversal attacks
Database BLOB — Advantages / Disadvantages
Advantages
  • Single source of truth — one backup covers everything
  • Transactionally consistent with related rows
  • No separately exposed file path to secure
Disadvantages
  • Slower reads/writes for large files
  • Database grows large and becomes harder to scale
